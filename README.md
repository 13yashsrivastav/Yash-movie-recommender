# Yash Movie Recommender System 🎬

This is a content-based movie recommendation web app built using:

- Python
- Streamlit
- Scikit-learn
- OMDb API

## Features
- Movie similarity recommendations
- Poster display
- Interactive UI
- Live deployment

## Live App
https://yash-movie-recommender-mkuctdq4b6milbyu7pyndw.streamlit.app/

## How it works
The system uses NLP vectorization and cosine similarity to recommend movies based on genre, keywords, and overview.
